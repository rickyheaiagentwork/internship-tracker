# Ricky — internship fit profile

Eternity / cron use this when ranking LinkedIn / careers / seed-list hits.

## Hard requirements (always)

- **Summer 2027 only** — skip Fall 2026, Spring 2027, Winter, Rolling (unless the posting is explicitly Summer 2027)
- **United States only** — onsite/hybrid/remote must be US-based
- **Undergraduate (BS) only** — skip MS-only and PhD-only

## Strong yes (priority order)

### 1. AI / Machine Learning (highest)

- LLMs, NLP, RL, multimodal, computer vision, applied ML
- ML infra / GPU / inference / training platforms
- SWE with clear ML flavor (platform, data for ML, model serving)

### 2. Bio-AI / medicine / pharma / biomedical data (highest)

- **AI in medicine / healthcare / clinical**: medical imaging AI, clinical ML, digital health ML, EHR/NLP
- **AI in pharma / drug discovery**: generative chemistry, target discovery, ADMET ML, wet-lab automation + ML
- **Biomedical data analytics**: bioinformatics, computational biology, genomics / multi-omics analysis, biomarker analytics, real-world evidence (RWE) data science
- Comp bio / drug discovery ML at biotech & Big Pharma (undergrad-eligible)

### 3. Related SWE / Quant (secondary)

- Strong SWE at priority tech companies (still keep)
- Quant / trading roles are **optional** — only add if capacity remains after AI/ML + Bio-AI

## Priority companies

1. **Big tech AI:** NVIDIA, Google / DeepMind, Microsoft, Amazon, Meta, Apple  
2. **Frontier AI labs:** OpenAI, Anthropic, Cohere, Mistral, Hugging Face, Scale AI, W&B  
3. **Bio-AI / biotech:** Recursion, Insitro, Schrödinger, Atomwise, Generate Biomedicines, Deep Genomics, Genesis Therapeutics, Isomorphic Labs, BenchSci, PathAI, Owkin, Tempus, Flatiron Health, Verily, Illumina, 10x Genomics  
4. **Pharma / medicine AI:** Moderna, Genentech / Roche, Amgen, Gilead, Pfizer, Merck, Novartis, AbbVie, Biogen, Bristol Myers Squibb, IQVIA, Natera, Guardant Health  

## Hard no

- Invented / unverified postings
- Fall 2026 / off-season roles
- MS-only or PhD-only roles
- Non-US locations
- Auto-submitting applications
- Pure ops / audit / HR / marketing / industrial BA with no CS/ML/data science
